# Etapas para construir o ambiente Docker a partir das imagens .tar:

## 1. Acesse via SSH
ssh usuario_da_vm@IP_DA_VM

## 2. Entre na pasta que você acabou de transferir
cd /home/usuario_da_vm/Deploy_PF

## 3. Carregue as imagens para dentro do Docker da VM
sudo docker load -i opera_app_image.tar
sudo docker load -i ml_engine_image.tar

## 3.1
Alterar o arquivo docker-compose:
```
 services:
   opera-app:
-    build: .
+    image: <NOME_DA_IMAGEM_OPERA_APP> 
...
   opera-admin:
-    build: .
+    image: <NOME_DA_IMAGEM_OPERA_APP>  # Usa a mesma imagem do Frontend
...
   ml-engine:
-    build: 
-      context: ../Proj_App   -- LLM-API - Vector_Engine_2
+    image: <NOME_DA_IMAGEM_ML_ENGINE>  # Ex: proj_app--llm-api-docs_analyzer_3-ml-engine:latest
     container_name: opera-ia-ml-engine
...
```

## 4. Suba a infraestrutura completa (Flet, Admin e ML-Engine) em background
sudo docker-compose up -d

ou sudo docker-compose up -d --force-recreate

## 5. Verifique se os 3 contêineres estão rodando
sudo docker ps
